# 🤖 PETS — AI Expense Tracker

**PETS** (Personal Expense Tracking System) is a full-stack, AI-powered financial application designed to simplify expense management, predict future spending trends, and flag unusual transactions using machine learning algorithms.

---

## ✨ Features

* 📊 **Interactive Financial Dashboard:** Real-time visibility into overall spending, income, and account balances.
* 🏷️ **Automated Expense Categorization:** Uses a trained **TF-IDF + Scikit-Learn ML model** to auto-predict category classification based on transaction descriptions.
* 📈 **Time-Series Expense Forecasting:** Leverages historical spending patterns to forecast future monthly expense bounds (upper/lower limits).
* 🚨 **Spending Anomaly Detection:** Flags irregular or unexpectedly high transactions automatically.
* 🔒 **Secure Authentication:** User authentication and protected API endpoints.
* 🔮 **Smart Budget Recommendations** *(Coming Soon)*: Intelligent, tailored budget limits based on ML spending insights.

---

## 🛠️ Tech Stack

### **Frontend**
* **Framework:** React.js (Vite)
* **Styling:** Tailwind CSS / Custom CSS
* **Icons & Charts:** Lucide React, Chart.js / Recharts

### **Backend**
* **Framework:** Python (FastAPI / Uvicorn)
* **Machine Learning:** Scikit-Learn, NumPy, Pandas
* **Database:** SQLite / PostgreSQL (Supabase)
